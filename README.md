# datasource-gallery-fire-selfies-05

A static web gallery of K. S. Ernest (iFire) Lee's photographs, one of a series split across repositories.

## What it is for

It publishes the photographs as browsable albums. `config.json` sets the gallery's title, sorting and theme, and `custom.css` adjusts its look.

## Build and run

The gallery workflow builds the site with a static gallery generator in a container on each push to the default branch, and publishes it as the repository's web pages. Adding images under `gallery/` is the whole process.
